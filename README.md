# W3Schools Header & Navigation Menu

A frontend practice project that recreates the header and navigation menu of the W3Schools website using HTML and CSS.

## Project Overview

This project is a recreation of the W3Schools header interface. It was created to practice HTML structure, CSS styling, navigation menus, grid layout, buttons, search input, icons, links, and hover effects.

## Features

- W3Schools-style logo and header
- Main navigation menu
- Tutorials, References, Exercises and Certificates links
- Search bar with search icon
- More options button
- Practice, Space, Academy, Upgrade and Get Certificates links
- Sign In button
- Secondary navigation menu
- Hover effects on navigation links
- External links to W3Schools pages
- CSS Grid layout for the main header

## Technologies Used

- HTML5

- CSS Flex/Float-based Navigation
